# UserBalanceController (Баланс пользователей)

Контроллер отвечает за просмотр текущего баланса лицевых счетов пользователей (родителей/учеников) и ручную корректировку баланса администратором.

## Эндпоинты

### 1. Получить баланс пользователя
* **URL**: `/user-balance/:userId`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает текущее состояние баланса (доступные средства, количество оплаченных занятий) для указанного пользователя.

### 2. Корректировка баланса (начисление/списание вручную)
* **URL**: `/user-balance/:userId/adjust`
* **Метод**: `POST`
* **Логика работы**:
  * Позволяет администратору вручную начислить или списать средства/занятия с баланса пользователя с указанием причины (комментария).
  * Фиксирует транзакцию в истории баланса.
