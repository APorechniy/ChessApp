# StudentsService (Сервис учеников)

Сервис `StudentsService` управляет личными карточками учеников, контактными данными их родителей, историей обучения и текущим статусом активности.

## Зависимости

- `AuthRepository` — создание учетных записей для личного кабинета ученика/родителя.
- `StudentsRepository` — управление персональными данными учеников.
- `UserBalanceRepository` — инициализация и проверка баланса занятий.

## Функционал и логика работы

1. **Создание ученика:**
   - Регистрация учетной записи в системе.
   - Создание профиля ученика с указанием контактов родителей, даты рождения и начального уровня.
   - Инициализация нулевого баланса занятий.

2. **Обновление профиля:**
   - Изменение контактных данных, перевод в архивный статус.
