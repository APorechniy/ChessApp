# Модуль «Задачи»

## Назначение
Интерактивный тренажер для решения шахматных задач на тактику, эндшпиль и дебютные ловушки. Помогает ученикам развивать тактическое зрение.

## Функционал
* **Интерактивная шахматная доска:** Возможность делать ходы на доске с автоматической проверкой правильности решения.
* **Категоризация задач:** Фильтрация по темам (мат в 1 ход, вилка, связка, отвлечение) и уровню сложности.
* **Создание задач тренером:** Конструктор задач с возможностью расстановки фигур (FEN) и записи правильной последовательности ходов.
* **История решений:** Сохранение результатов попыток ученика для последующего анализа тренером.

## Логические связи с другими модулями
* **С Учениками (`/students`):** Результаты решения задач (процент успеха, скорость решения) записываются в профиль ученика.
* **С Отчетами (`/reports`):** На основе решенных задач строится аналитика успеваемости учеников по различным тактическим темам.
