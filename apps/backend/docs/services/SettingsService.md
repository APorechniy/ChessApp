# SettingsService (Сервис глобальных настроек)

Сервис `SettingsService` управляет глобальными конфигурационными параметрами системы, такими как стоимость одного занятия, лимиты на задолженность, контактные данные школы и другие константы.

## Зависимости

- `SettingsRepository` — чтение и запись настроек в базу данных.

## Функционал и логика работы

1. **Получение настроек:**
   - Возвращает текущие активные настройки системы.

2. **Обновление настроек:**
   - Позволяет администраторам изменять параметры работы школы в реальном времени.
