# UserBalanceService (Сервис баланса пользователей)

Сервис `UserBalanceService` предоставляет низкоуровневый API для работы с балансом занятий пользователей. Он используется другими сервисами (например, `PaymentsService` и `AttendancesService`) для непосредственного изменения числовых значений баланса.

## Зависимости

- `UserBalanceRepository` — выполнение SQL-запросов на обновление баланса.

## Функционал и логика работы

1. **Получение баланса:**
   - Запрос текущего количества оплаченных занятий у конкретного ученика.

2. **Изменение баланса:**
   - Инкремент или декремент баланса на заданное количество занятий.
