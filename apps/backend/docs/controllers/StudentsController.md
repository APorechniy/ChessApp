# StudentsController (Ученики)

Контроллер отвечает за управление профилями учеников, их контактными данными, родителями и балансом занятий.

## Эндпоинты

### 1. Получить список учеников
* **URL**: `/students`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает список всех учеников с возможностью фильтрации по группе, статусу обучения и балансу.

### 2. Создать профиль ученика
* **URL**: `/students`
* **Метод**: `POST`
* **Логика работы**:
  * Создает новую карточку ученика, привязывает контактные данные родителей, создает лицевой счет (баланс).

### 3. Получить профиль ученика по ID
* **URL**: `/students/:id`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает детальную информацию об ученике, включая историю его посещений, баланс и оценки.

### 4. Обновить профиль ученика
* **URL**: `/students/:id`
* **Метод**: `PUT`
* **Логика работы**:
  * Обновляет персональные данные ученика.

### 5. Удалить профиль ученика
* **URL**: `/students/:id`
* **Метод**: `DELETE`
* **Логика работы**:
  * Переводит ученика в архив или полностью удаляет его профиль из системы.
