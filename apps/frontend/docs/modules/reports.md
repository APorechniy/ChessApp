# Модуль «Отчеты»

## Назначение
Инструмент для администраторов и тренеров, позволяющий агрегировать данные о работе школы, посещаемости занятий и прогрессе учеников за выбранный период.

## Функционал
* **Отчет по успеваемости:** Сводная таблица по решенным задачам, росту рейтинга и освоенным темам обучения.
* **Отчет по посещаемости:** Анализ пропусков занятий учениками и фактически проведенных часов тренерами.
* **Экспорт данных:** Возможность выгрузки отчетов в удобные форматы для печати или дальнейшего анализа.

## Логические связи с другими модулями
* **С Учениками (`/students`):** Извлекает персональные данные учеников и их текущие показатели.
* **С Расписанием (`/timetable`):** Получает историю проведенных занятий и отметки о присутствии.
* **С Задачами (`/tasks`):** Анализирует активность учеников в решении тактических упражнений.
