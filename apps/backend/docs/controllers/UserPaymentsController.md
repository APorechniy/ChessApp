# UserPaymentsController (История платежей)

Контроллер предоставляет доступ к истории всех финансовых транзакций, совершенных пользователями через платежные шлюзы или наличными.

## Эндпоинты

### 1. Получить историю платежей пользователя
* **URL**: `/user-payments`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает список транзакций текущего авторизованного пользователя (или всех пользователей для администратора).
  * Поддерживает фильтрацию по дате, статусу платежа (успешно, в обработке, ошибка) и типу оплаты.
