# LearningTopicsController (Темы обучения)

Контроллер управляет учебной программой, темами занятий и планами уроков.

## Эндпоинты

### 1. Получить список учебных тем
* **URL**: `/learning-topics`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает иерархический или линейный список тем обучения, разделенных по уровням сложности.

### 2. Создать учебную тему
* **URL**: `/learning-topics`
* **Метод**: `POST`
* **Логика работы**:
  * Создает новую тему обучения (название, описание, рекомендуемый уровень, методические материалы).

### 3. Обновить учебную тему
* **URL**: `/learning-topics/:id`
* **Метод**: `PUT`
* **Логика работы**:
  * Обновляет информацию о теме.

### 4. Удалить учебную тему
* **URL**: `/learning-topics/:id`
* **Метод**: `DELETE`
* **Логика работы**:
  * Удаляет тему из базы данных.
