# ChessOpeningsController (Шахматные дебюты)

Контроллер предоставляет доступ к справочнику шахматных дебютов, используемому в учебных целях для классификации сыгранных партий и обучения теории.

## Эндпоинты

### 1. Получить список дебютов
* **URL**: `/chess-openings`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает список дебютов с их названиями, кодами ECO и начальными ходами.

### 2. Добавить новый дебют в справочник
* **URL**: `/chess-openings`
* **Метод**: `POST`
* **Логика работы**:
  * Позволяет администратору или тренеру добавить новый дебют (название, ECO-код, строка ходов/FEN).

### 3. Удалить дебют из справочника
* **URL**: `/chess-openings/:id`
* **Метод**: `DELETE`
* **Логика работы**:
  * Удаляет дебют из справочника по его ID.
