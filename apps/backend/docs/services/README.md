# Документация по сервисам системы

Добро пожаловать в техническую документацию бизнес-логики (сервисного слоя) приложения. Архитектура проекта построена на разделении ответственности: контроллеры обрабатывают HTTP-запросы, репозитории взаимодействуют с базой данных MySQL через TypeORM, а вся ключевая бизнес-логика сосредоточена в сервисах.

## Общие архитектурные принципы

- **Инъекция зависимостей (DI):** Все зависимости (репозитории и другие сервисы) передаются в конструктор класса при инициализации в `server.ts`.
- **Обработка ошибок:** Сервисы перехватывают ошибки и пробрасывают их выше для обработки глобальным Middleware или контроллером.
- **Транзакционность:** Операции, затрагивающие несколько таблиц (например, списание баланса при посещении или проведение платежа), требуют строгого контроля целостности данных.
