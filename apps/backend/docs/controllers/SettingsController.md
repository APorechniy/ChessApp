# SettingsController (Настройки)

Контроллер управляет глобальными системными настройками приложения (стоимость занятий по умолчанию, параметры интеграции, контактные данные).

## Эндпоинты

### 1. Получить системные настройки
* **URL**: `/settings`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает ключ-значение пары глобальных настроек системы.

### 2. Обновить системные настройки
* **URL**: `/settings`
* **Метод**: `PUT`
* **Логика работы**:
  * Принимает новые значения настроек и сохраняет их в базе данных.
