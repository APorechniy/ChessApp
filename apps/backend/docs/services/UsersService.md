# UsersService (Сервис пользователей и прав)

Сервис `UsersService` является связующим звеном для управления всеми типами пользователей в системе (администраторы, тренеры, ученики). Он отвечает за общие операции над пользователями и разграничение прав доступа.

## Зависимости

- `CoachesRepository` — проверка связи пользователя с профилем тренера.
- `StudentsRepository` — проверка связи пользователя с профилем ученика.
- `UsersRepository` — общие операции над таблицей пользователей.

## Функционал и логика работы

1. **Управление пользователями:**
   - Получение списка всех пользователей системы с их ролями.
   - Блокировка и разблокировка учетных записей.
   - Изменение системных ролей (например, назначение тренера администратором).
