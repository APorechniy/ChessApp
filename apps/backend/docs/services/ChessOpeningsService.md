# ChessOpeningsService (Сервис шахматных дебютов)

Сервис `ChessOpeningsService` управляет справочником шахматных дебютов. Он используется для обучения учеников, классификации сыгранных ими партий и быстрого поиска теоретических вариантов.

## Зависимости

- `ChessOpeningsRepository` — доступ к таблице дебютов.

## Функционал и логика работы

1. **Получение списка дебютов (`getChessOpenings`):**
   - Возвращает список всех зарегистрированных дебютов.

2. **Создание дебюта (`createChessOpening`):**
   - Генерирует уникальный UUID для нового дебюта.
   - Проверяет наличие обязательного поля `name`.
   - Сохраняет дебют с его ходами и FEN-начальной позицией.
