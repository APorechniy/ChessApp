**Скрипты в этой папке используются для инициализии баз данных в общем контейнере**

Скрипт инициализации проверяет переменные с клиентами и паролями и создает новую базу данных, если для клиента
она еще не существует.
В папке с дампами можно положить INIT-запросы для создания базы.
