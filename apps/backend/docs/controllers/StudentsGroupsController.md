# StudentsGroupsController (Группы студентов)

Контроллер управляет учебными группами школы, расписанием групп и распределением учеников по группам.

## Эндпоинты

### 1. Получить список групп
* **URL**: `/students-groups`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает список всех учебных групп с информацией о тренере, уровне и количестве учеников.

### 2. Создать учебную группу
* **URL**: `/students-groups`
* **Метод**: `POST`
* **Логика работы**:
  * Создает новую группу с указанием названия, тренера, расписания и уровня подготовки.

### 3. Обновить информацию о группе
* **URL**: `/students-groups/:id`
* **Метод**: `PUT`
* **Логика работы**:
  * Обновляет параметры группы (название, тренер, расписание).

### 4. Добавить ученика в группу
* **URL**: `/students-groups/:id/students`
* **Метод**: `POST`
* **Логика работы**:
  * Привязывает ученика к указанной группе.

### 5. Удалить ученика из группы
* **URL**: `/students-groups/:id/students/:studentId`
* **Метод**: `DELETE`
* **Логика работы**:
  * Исключает ученика из состава группы.
