# AuthController (Авторизация)

Контроллер отвечает за аутентификацию пользователей (тренеров, администраторов, учеников/родителей), управление сессиями и выдачу JWT-токенов.

## Эндпоинты

### 1. Вход в систему (Login)
* **URL**: `/auth/login`
* **Метод**: `POST`
* **Логика работы**:
  * Принимает логин (email/телефон) и пароль.
  * Проверяет существование пользователя и сверяет хэш пароля.
  * Генерирует JWT-токен, содержащий ID пользователя и его роль.
  * Устанавливает JWT-токен в HTTP-only cookie `jwt-token`.
  * Возвращает данные пользователя (без пароля).

### 2. Выход из системы (Logout)
* **URL**: `/auth/logout`
* **Метод**: `POST`
* **Логика работы**:
  * Очищает HTTP-only cookie `jwt-token` на клиенте, завершая сессию пользователя.

### 3. Проверка текущей сессии (Me)
* **URL**: `/auth/me`
* **Метод**: `GET`
* **Логика работы**:
  * Извлекает JWT-токен из cookies.
  * Декодирует его и проверяет валидность.
  * Возвращает профиль текущего авторизованного пользователя.
