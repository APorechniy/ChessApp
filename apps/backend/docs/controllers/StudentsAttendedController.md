# StudentsAttendedController (Присутствие студентов)

Контроллер отвечает за детальный учет присутствия конкретных учеников на уроках, выставление индивидуальных оценок за урок и фиксацию пропусков.

## Эндпоинты

### 1. Отметить присутствие/отсутствие ученика
* **URL**: `/students-attended`
* **Метод**: `POST`
* **Логика работы**:
  * Фиксирует статус присутствия ученика на конкретном занятии (присутствовал, отсутствовал по уважительной причине, отсутствовал без уважительной причины).
  * Корректирует баланс занятий ученика в зависимости от статуса пропуска.

### 2. Обновить оценку или комментарий ученика за урок
* **URL**: `/students-attended/:id`
* **Метод**: `PUT`
* **Логика работы**:
  * Позволяет тренеру изменить оценку за работу на уроке, оценку за домашнее задание или добавить текстовый комментарий для родителей.
