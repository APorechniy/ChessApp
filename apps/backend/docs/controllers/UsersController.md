# UsersController (Пользователи и Тренеры)

Контроллер управляет учетными записями всех пользователей системы: администраторов, тренеров и клиентов.

## Эндпоинты

### 1. Получить список пользователей
* **URL**: `/users`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает список пользователей системы с фильтрацией по ролям (например, только тренеры или только администраторы).

### 2. Создать пользователя
* **URL**: `/users`
* **Метод**: `POST`
* **Логика работы**:
  * Создает новую учетную запись пользователя, хэширует пароль, назначает роль (администратор, тренер, родитель).

### 3. Обновить профиль пользователя
* **URL**: `/users/:id`
* **Метод**: `PUT`
* **Логика работы**:
  * Обновляет контактные данные, имя или роль пользователя.

### 4. Удалить пользователя
* **URL**: `/users/:id`
* **Метод**: `DELETE`
* **Логика работы**:
  * Удаляет учетную запись пользователя из системы.
