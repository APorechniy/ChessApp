# AttendancesService (Сервис посещаемости и занятий)

Сервис `AttendancesService` является одним из ключевых модулей системы. Он отвечает за планирование занятий, учет посещаемости учеников, фиксацию выполненных задач и автоматическое списание баланса занятий у учеников.

## Зависимости

Сервис зависит от следующих репозиториев:
- `AttendancesRepository` — управление записями занятий.
- `AttendanceMainTasksRepository` — привязка основных задач к занятию.
- `AttendanceAdditionalTasksRepository` — привязка дополнительных задач к занятию.
- `AttendancePresetRepository` — доступ к шаблонам занятий.
- `SettingsRepository` — получение глобальных настроек (например, стоимость занятия по умолчанию).
- `StudentsAttendedRepository` — фиксация присутствия конкретных учеников.
- `StudentsBalanceTransactionRepository` — логирование транзакций изменения баланса.
- `StudentsGroupsRepository` — получение состава учебных групп.
- `UserBalanceRepository` — изменение баланса занятий учеников.

## Функционал и логика работы

1. **Создание занятия (`createAttendance`):**
   - Создается запись занятия с указанием тренера, темы обучения, даты и времени.
   - К занятию привязываются основные и дополнительные задачи.
   - Автоматически определяются ученики, которые должны присутствовать (на основе выбранной группы).

2. **Фиксация посещаемости и списание баланса:**
   - При отметке присутствия ученика на занятии проверяется его текущий баланс.
   - Происходит списание занятий с баланса ученика согласно тарифу.
   - Создается запись в истории транзакций баланса (`StudentsBalanceTransaction`).

3. **Редактирование и отмена занятий:**
   - При изменении статуса посещения (например, ученик не пришел по уважительной причине) баланс может быть возвращен.
   - При удалении занятия все списания баланса откатываются.
