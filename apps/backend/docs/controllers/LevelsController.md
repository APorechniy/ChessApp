# LevelsController (Уровни сложности)

Контроллер управляет уровнями подготовки учеников (например: Начинающий, Разрядник, КМС и т.д.).

## Эндпоинты

### 1. Получить список уровней
* **URL**: `/levels`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает список всех доступных уровней подготовки в системе.

### 2. Создать уровень
* **URL**: `/levels`
* **Метод**: `POST`
* **Логика работы**:
  * Добавляет новый уровень подготовки с описанием критериев его достижения.

### 3. Удалить уровень
* **URL**: `/levels/:id`
* **Метод**: `DELETE`
* **Логика работы**:
  * Удаляет уровень подготовки из системы.
