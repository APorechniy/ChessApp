# ChessGamesController (Шахматные партии)

Контроллер предназначен для сохранения, просмотра и анализа сыгранных учениками шахматных партий (в формате PGN или базы данных ходов).

## Эндпоинты

### 1. Получить список партий
* **URL**: `/chess-games`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает список партий с возможностью фильтрации по ID ученика, результату, дате или дебюту.

### 2. Сохранить сыгранную партию
* **URL**: `/chess-games`
* **Метод**: `POST`
* **Логика работы**:
  * Сохраняет запись партии (имена игроков, результат, список ходов в формате PGN, дату проведения).
  * Привязывает партию к профилям учеников для последующего анализа тренером.

### 3. Получить детальную информацию о партии
* **URL**: `/chess-games/:id`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает полную информацию о партии, включая PGN-строку для интерактивной доски.

### 4. Удалить запись партии
* **URL**: `/chess-games/:id`
* **Метод**: `DELETE`
* **Логика работы**:
  * Удаляет запись партии из базы данных.
