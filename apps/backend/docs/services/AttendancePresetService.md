# AttendancePresetService (Сервис шаблонов занятий)

Сервис `AttendancePresetService` предназначен для управления шаблонами (пресетами) занятий. Шаблоны позволяют быстро создавать повторяющиеся занятия (например, регулярные групповые тренировки по расписанию) без необходимости каждый раз вводить данные заново.

## Зависимости

- `AttendancePresetRepository` — управление шаблонами в базе данных.
- `AttendancesRepository` — создание занятий на основе шаблонов.

## Функционал и логика работы

1. **Создание шаблона (`createPreset`):**
   - Сохранение структуры занятия: день недели, время начала/окончания, тренер, группа, тема по умолчанию.
   - Валидация корректности заполнения полей шаблона.

2. **Применение шаблона (`applyPreset`):**
   - Генерация одного или нескольких занятий на основе выбранного шаблона на указанный период времени.

3. **Управление шаблонами:**
   - Получение списка активных шаблонов, редактирование параметров и удаление.
