# Модуль «Ученики»

## Назначение
Модуль предназначен для ведения базы данных учеников шахматной школы, отслеживания их контактной информации, привязки к тренерам и группам, а также просмотра их индивидуального прогресса.

## Функционал
* **Просмотр списка учеников:** Таблица с фильтрацией по уровню игры (разряду), тренеру и статусу обучения.
* **Карточка ученика:** Детальная информация (ФИО, дата рождения, контакты родителей, текущий рейтинг, история сыгранных партий и решенных задач).
* **Управление данными (CRUD):** Добавление новых учеников администратором, редактирование профилей тренерами или администраторами.

## Логические связи с другими модулями
* **С Расписанием (`/timetable`):** Ученики привязываются к конкретным группам или индивидуальным слотам в расписании. При изменении расписания ученики получают уведомления.
* **С Задачами (`/tasks`):** Статистика решенных учеником задач отображается в его профиле. Тренер может назначать домашние задания из базы задач конкретному ученику.
* **С Отчетами (`/reports`):** Данные учеников (посещаемость занятий, динамика рейтинга, успеваемость) являются основным источником для генерации отчетов.
