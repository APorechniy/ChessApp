# AttendancePresetController (Шаблоны посещаемости)

Контроллер управляет шаблонами (пресетами) занятий, которые позволяют быстро создавать повторяющиеся уроки с предзаполненными параметрами (время, группа, стоимость, задачи).

## Эндпоинты

### 1. Получить список шаблонов
* **URL**: `/attendance-presets`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает список всех сохраненных шаблонов занятий для быстрого выбора при планировании расписания.

### 2. Создать шаблон занятия
* **URL**: `/attendance-presets`
* **Метод**: `POST`
* **Логика работы**:
  * Сохраняет новый шаблон с указанием группы, темы по умолчанию, стоимости и списка задач.

### 3. Обновить шаблон занятия
* **URL**: `/attendance-presets/:id`
* **Метод**: `PUT`
* **Логика работы**:
  * Изменяет параметры существующего шаблона по его ID.

### 4. Удалить шаблон занятия
* **URL**: `/attendance-presets/:id`
* **Метод**: `DELETE`
* **Логика работы**:
  * Удаляет шаблон из базы данных. Это не влияет на уже созданные на основе этого шаблона занятия.
