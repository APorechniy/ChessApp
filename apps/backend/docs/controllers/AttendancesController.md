# AttendancesController (Посещаемость)

Контроллер отвечает за управление посещаемостью занятий, фиксацию присутствия учеников, выставление оценок за работу на уроке, а также за привязку основных и дополнительных задач к урокам.

## Эндпоинты

### 1. Получить список посещаемости
* **URL**: `/attendances`
* **Метод**: `GET`
* **Логика работы**:
  * Извлекает список занятий с фильтрацией по группе, дате или тренеру.
  * Подгружает связанные данные об учениках, присутствовавших на занятии.

### 2. Создать запись посещаемости (Урок)
* **URL**: `/attendances`
* **Метод**: `POST`
* **Логика работы**:
  * Создает новую запись урока для указанной группы.
  * Инициализирует список присутствующих учеников на основе текущего состава группы.
  * Списывает оплату за занятие с баланса учеников (если настроено автоматическое списание).

### 3. Получить детальную информацию о занятии
* **URL**: `/attendances/:id`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает подробную информацию о конкретном занятии по его ID, включая список присутствующих учеников, оценки, решенные задачи и комментарии тренера.

### 4. Обновить запись посещаемости
* **URL**: `/attendances/:id`
* **Метод**: `PUT`
* **Логика работы**:
  * Обновляет метаданные занятия (тема, дата, время проведения, комментарий).

### 5. Удалить запись посещаемости
* **URL**: `/attendances/:id`
* **Метод**: `DELETE`
* **Логика работы**:
  * Удаляет запись о занятии.
  * Возвращает списанные средства на баланс учеников, если занятие было оплачено.
  * Удаляет связанные записи о присутствии и решенных задачах.
