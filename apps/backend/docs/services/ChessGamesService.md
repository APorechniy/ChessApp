# ChessGamesService (Сервис шахматных партий)

Сервис `ChessGamesService` отвечает за сохранение, систематизацию и анализ шахматных партий, сыгранных учениками на занятиях или турнирах.

## Зависимости

- `ChessGamesRepository` — сохранение и выборка партий из базы данных.

## Функционал и логика работы

1. **Сохранение партии:**
   - Запись метаданных партии (белые, черные, результат, дата, турнир).
   - Сохранение нотации партии в формате PGN (Portable Game Notation) или текущей позиции в формате FEN (Forsyth-Edwards Notation).

2. **Просмотр истории партий:**
   - Получение списка партий конкретного ученика для анализа тренером.
