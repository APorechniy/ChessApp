# StudentsGroupsService (Сервис учебных групп)

Сервис `StudentsGroupsService` управляет учебными группами (классами), распределением учеников по группам и связью групп с расписанием занятий.

## Зависимости

- `AttendancesRepository` — проверка занятий группы.
- `StudentsAttendedRepository` — проверка посещаемости группы.
- `StudentsGroupsRepository` — управление составом групп.
- `UserGroupsRepository` — связь пользователей с группами.

## Функционал и логика работы

1. **Создание и редактирование групп:**
   - Определение названия группы, уровня подготовки и максимального количества учеников.

2. **Управление составом группы:**
   - Добавление учеников в группу, перевод ученика из одной группы в другую.
