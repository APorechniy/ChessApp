# UserPaymentsService (Сервис истории транзакций)

Сервис `UserPaymentsService` отвечает за ведение детальной истории всех финансовых операций пользователей (поступление средств, списание за абонементы, возвраты).

## Зависимости

- `UserPaymentsRepository` — запись и чтение истории платежей.

## Функционал и логика работы

1. **Ведение истории:**
   - Добавление записей о платежах с указанием даты, суммы, способа оплаты и назначения платежа.
   - Получение выписки по платежам для конкретного пользователя.
