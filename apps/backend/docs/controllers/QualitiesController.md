# QualitiesController (Качества учеников)

Контроллер управляет справочником качеств учеников (например: тактическое зрение, усидчивость, эндшпильная техника), которые тренеры могут оценивать на занятиях.

## Эндпоинты

### 1. Получить список качеств
* **URL**: `/qualities`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает список всех оцениваемых качеств.

### 2. Создать новое качество
* **URL**: `/qualities`
* **Метод**: `POST`
* **Логика работы**:
  * Добавляет новое качество в справочник.

### 3. Удалить качество
* **URL**: `/qualities/:id`
* **Метод**: `DELETE`
* **Логика работы**:
  * Удаляет качество из справочника.
