# AuthService (Сервис аутентификации)

Сервис `AuthService` отвечает за безопасность приложения, регистрацию пользователей, аутентификацию, управление сессиями и разграничение прав доступа.

## Зависимости

- `AuthRepository` — проверка учетных данных, сохранение хэшей паролей и токенов.

## Функционал и логика работы

1. **Регистрация пользователей:**
   - Хеширование паролей перед сохранением в базу данных.
   - Проверка уникальности логина/email.

2. **Вход в систему (Login):**
   - Сравнение введенного пароля с хэшем в БД.
   - Генерация пары токенов: Access Token (короткоживущий) и Refresh Token (долгоживущий).

3. **Обновление токенов (Refresh Token):**
   - Валидация Refresh Token и выдача новой пары токенов для бесшовной работы пользователя.

4. **Выход из системы (Logout):**
   - Инвалидация Refresh Token в базе данных.
