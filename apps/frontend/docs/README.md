# Документация проекта: Шахматная Школа

Добро пожаловать в техническую документацию системы управления шахматной школой. Данный документ является разводящей страницей, описывающей общую архитектуру, модули системы, их взаимосвязи и ролевую модель.

## Общая архитектура и логические связи

Система построена по модульному принципу. Все модули взаимодействуют друг с другом через общие сущности (такие как Пользователи/Ученики) и используют единый набор независимых UI-компонентов (атомов) и конфигурационных файлов.

```
                     [ Панель управления (Дашборд) ]
                                    │
         ┌──────────────────────────┼──────────────────────────┐
         ▼                          ▼                          ▼
   [ Ученики ] <────────────> [ Расписание ] <────────────> [ Задачи ]
         │                          │                          │
         └───────────┬──────────────┴──────────────────────────┘
                     ▼
                 [ Отчеты ] ◄─── [ Дебюты и Партии ] (Справочные материалы)
```

---

## Модули системы

Ниже представлены ссылки на подробное описание каждого модуля:

1. **[Модуль «Ученики»](modules/students.md)**
   * **Назначение:** Управление учетными записями, профилями и успеваемостью учеников.
   * **Доступ:** Администраторы, Тренеры.

2. **[Модуль «Расписание»](modules/timetable.md)**
   * **Назначение:** Планирование занятий, управление регулярными тренировками (RRule) и календарем.
   * **Доступ:** Администраторы, Тренеры, Ученики, Родители.

3. **[Модуль «Задачи»](modules/tasks.md)**
   * **Назначение:** База шахматных задач на тактику и стратегию, интерактивное решение.
   * **Доступ:** Администраторы, Тренеры, Ученики.

4. **[Модуль «Отчеты»](modules/reports.md)**
   * **Назначение:** Аналитика успеваемости, посещаемости и активности учеников.
   * **Доступ:** Администраторы, Тренеры.

5. **[Модули «Дебюты и Партии»](modules/chess-openings-games.md)**
   * **Назначение:** Интерактивная база шахматной теории, разбор знаменитых партий и дебютных линий.
   * **Доступ:** Администраторы, Тренеры, Ученики (только партии).

## Независимые структуры и контент

Для обеспечения переиспользуемости кода и единого источника правды (Single Source of Truth) в проекте выделены независимые структуры:

* **[Атомы, Контент и Календарные структуры](structures/independent.md)**
  * Конфигурация бокового меню (`sidebar-items.ts`)
  * Карточки дашборда (`dashboard-cards.ts`)
  * Выпадающее меню профиля (`expanded-menu.ts`)
  * Календарные константы и правила повторений (`calendar.ts`)
  * UI-компоненты (Атомы и Иконки)
