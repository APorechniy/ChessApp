# TasksController (Задачи)

Контроллер управляет базой шахматных задач (задачников), которые тренеры могут назначать в качестве классной или домашней работы.

## Эндпоинты

### 1. Получить список задач
* **URL**: `/tasks`
* **Метод**: `GET`
* **Логика работы**:
  * Возвращает список задач с фильтрацией по теме, сложности или источнику (FEN/картинка).

### 2. Создать задачу
* **URL**: `/tasks`
* **Метод**: `POST`
* **Логика работы**:
  * Добавляет новую задачу в базу данных (диаграмма в формате FEN, решение, описание, уровень сложности).

### 3. Обновить задачу
* **URL**: `/tasks/:id`
* **Метод**: `PUT`
* **Логика работы**:
  * Изменяет параметры существующей задачи.

### 4. Удалить задачу
* **URL**: `/tasks/:id`
* **Метод**: `DELETE`
* **Логика работы**:
  * Удаляет задачу из базы данных.
