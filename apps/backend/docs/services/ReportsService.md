# ReportsService (Сервис генерации отчетов)

Сервис `ReportsService` отвечает за формирование аналитических отчетов об успеваемости, посещаемости и активности учеников. Отчеты генерируются в формате Excel (Workbook) для последующей отправки родителям.

## Зависимости

- `AttendancesRepository` — получение истории занятий ученика.
- `StudentsAttendedRepository` — проверка фактов присутствия.
- `StudentsRepository` — получение личных данных ученика.

## Функционал и логика работы

1. **Генерация отчета по ученику (`createReport`):**
   - Извлекает все посещенные учеником занятия.
   - Собирает информацию о темах занятий, оценках (качествах), выполненных основных и дополнительных задачах, домашней работе.
   - Транслитерирует имя ученика для формирования названия файла.
   - Формирует Excel-документ с помощью библиотеки для работы с таблицами.
