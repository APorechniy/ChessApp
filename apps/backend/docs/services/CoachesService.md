# CoachesService (Сервис тренеров)

Сервис `CoachesService` управляет профилями тренерского состава, их учетными записями, ставками оплаты труда и расписанием работы.

## Зависимости

- `AuthRepository` — создание учетных записей для входа тренеров в систему.
- `CoachesRepository` — управление персональными данными тренеров.

## Функционал и логика работы

1. **Создание тренера:**
   - Одновременно создается системный пользователь (в таблице авторизации) и профиль тренера с его специализацией и ставкой.

2. **Управление профилем:**
   - Редактирование контактной информации, квалификации, изменение ставки за занятие.

3. **Получение информации:**
   - Вывод списка активных тренеров для назначения на занятия.
