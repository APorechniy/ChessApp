# ReportsController (Отчеты)

Контроллер отвечает за генерацию аналитических отчетов по посещаемости, успеваемости учеников и финансовой статистике школы.

## Эндпоинты

### 1. Получить отчет по посещаемости
* **URL**: `/reports/attendance`
* **Метод**: `GET`
* **Логика работы**:
  * Агрегирует данные о посещаемости за указанный период времени.
  * Возвращает статистику по группам, тренерам и проценту посещений.

### 2. Получить отчет по успеваемости учеников
* **URL**: `/reports/progress`
* **Метод**: `GET`
* **Логика работы**:
  * Собирает данные о решенных задачах, оценках на уроках и динамике изменения качеств учеников.
