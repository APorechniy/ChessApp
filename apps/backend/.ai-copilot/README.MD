# Ситема RAG для репозитория

## Реиндексация

Для реиндексации файлов необходимо выполнить

```
npm run ai:index
```

Команду необходимо выполнять в случае переименования файлов и директорий, создания новых файлов и директорий, удаления файлов и директорий.

## Компаньон

Для запуска AI-компаньона необходимо выполнить команду

```
npm run ai:work
```

После запуска команды в терминале можно будет ввести вопрос или дать небольшую задачу
